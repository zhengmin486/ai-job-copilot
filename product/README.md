# 产品文档

代码在仓库根目录，这里放 AI 产品经理方向的作品集材料。一页总览见 [00-作品集总览](00-作品集总览.md)。

口径先说在前面：

- **不放真实投递数据**。指标只写定义和口径，不写具体数字。
- **不引用个人能力库**。技能档位、能力话术、方向词清单一律不进这里；文档里出现的技术词都是产品规则或中性占位。
- **图用 Mermaid**，纯文本，跟代码一起 diff，不塞截图。
- **只写已经有的东西**。候选设计明确标注「未实现」，不当既成事实写。
- **用产品视角**。定位、需求、规则、评估一律第三人称；第一人称只出现在仓库首页的「为什么做」。

## 原型

[prototype.html](prototype.html) 是自包含的灰阶线框，六个页面用顶部标签切换，无外部依赖。前四页对应 `front/app` 里已有的路由；后两页是路线图里的候选设计，当前未实现，用来表达配置引导和反馈闭环两个产品判断。
