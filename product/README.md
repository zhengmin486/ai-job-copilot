# 产品文档

代码在仓库根目录，这里放产品侧的文档。按批次补，不一次堆完。

口径先说在前面：

- **不放真实投递数据**。指标只写定义和口径，不写具体数字。
- **不引用个人能力库**。技能档位、能力话术、方向词清单一律不进这里；文档里出现的技术词都是产品规则或中性占位。
- **图用 Mermaid**，纯文本，跟代码一起 diff，不塞截图。
- **只写已经有的东西**。规划中的功能标状态，不当既成事实写。
